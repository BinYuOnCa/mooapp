# ADR-0028：当日亏损触线后只拦买单

- **状态**：已定
- **日期**：2026-11-14
- **来源**：M4 代码审查第 5 条（2026-11-14 你的决定）；补充 ADR-0017、ADR-0021

## 决策

当日亏损触及 `max_daily_loss` 之后，卖单要不要拦

## 取值

- 触线后**只拒绝买单**；卖单照常检查其余规则（白名单、时段、可卖数量等），数量不超过可卖持仓（只减仓，ADR-0002）
- 规则引擎的保护性卖单、命令行的卖单都一样放行
- `halt_on_daily_loss` 为真时，触线仍会自动 halt（ADR-0017）；halt 期间新单（包括卖单）照旧被 halt 拒绝，要平仓先 `mooapp resume` 或在 App 里操作
- 与「当日盈亏不可用时只拦买单」（M4 确认点 2）一致

## 理由

亏损上限的目的是不再扩大风险。卖出只会减仓、降低风险；拦住卖单反而让你在亏损扩大时无法平仓（审查第 5 条的情形：没有自动 halt 或 halt 已解除时）。
