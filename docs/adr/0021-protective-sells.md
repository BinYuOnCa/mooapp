# ADR-0021：保护性卖单与限额

- **状态**：已定
- **日期**：2026-11-11
- **来源**：SPEC.md 第 9 节 Q12（2026-11-11 答复「同意」）

## 决策

止损止盈触发的市价卖单，在当日下单次数已满、单笔金额超限或已 halt 时还发不发

## 取值

当日下单次数和单笔金额不拦保护性卖单（只减仓，数量 ≤ 可卖持仓）；`protective` 标记只在来源为规则引擎的卖单上被承认，其他来源带此标记一律拒绝；halt 时规则引擎一并暂停，持仓保留并告警，由你决定是否手动平仓

## 理由

限额是为了防止加仓失控，不应阻止止损；只认规则引擎，防止 Agent 或命令行借标记绕过限额
