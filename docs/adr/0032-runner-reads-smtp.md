# ADR-0032：常驻进程（和 mooapp eod）读取 secrets 的 [smtp] 段

- **状态**：已定
- **日期**：2026-11-16
- **来源**：M5 计划问题 1（2026-11-16 你选「按建议」）；扩展 ADR-0029 的例外

## 决策

SIMULATE 下谁可以读 secrets、读哪些项

## 取值

- 常驻进程 `mooapp run` 与 `mooapp eod` 可以读 secrets 的 `[smtp]` 段（host、port、username、app_password），用于发送通知邮件；其余项照旧只在需要时由对应进程读取（`[resume] key` 见 ADR-0029）
- 每次重试发送前重新读取 `[smtp]`（改正密码后不必重启即可补发）；密码只在内存里，不写日志、不进 outbox、不进邮件正文
- 读不到或格式错误：通知器报警（终端 ALERT 与日志），邮件留在 outbox 里等下次重试；交易照常（SPEC 5.7）

## 理由

M5 验收 1 要求「SMTP 密码填错时交易照常，改正后补发」：发送方必须能拿到凭据，并且能在不重启的情况下读到改正后的值。
