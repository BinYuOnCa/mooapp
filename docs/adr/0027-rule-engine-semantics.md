# ADR-0027：规则引擎的触发与执行细节

- **状态**：已定
- **日期**：2026-11-14
- **来源**：M6a 计划（2026-11-14 你的答复）；补充 ADR-0005、0007、0008、0009、0021、0023 没有覆盖的细节

## 决策

止损止盈规则从「算出价格」到「卖出完成」之间，几种边界情况怎么处理

## 取值

1. **触发比较含边界**：逐笔行情 `last ≤ 止损价` 触发止损，`last ≥ 止盈价` 触发止盈；K 线用最低价和最高价判断，同样含边界。
2. **同一时段两边都碰到**（一根 K 线的最低价 ≤ 止损价，且最高价 ≥ 止盈价，先后顺序不明）：**按止盈算**（你的决定），并在 dry-run 输出和事件里注明「时段内先后顺序不明，按止盈计」。
3. **触发时入场单还有余量**：先经闸门撤掉入场单的剩余部分（撤单不受限额限制，ADR-0016），再按「已买入未卖出」的数量发市价卖单（ADR-0008）。撤单生效前入场单又成交的部分，补发卖单。
4. **卖单被闸门或券商拒绝**：下一笔行情到来时，如果同一边的触发条件仍然成立，就重发；如果价格已经回到两个触发价之间，规则回到监控状态，两边重新生效。累计失败 3 次后，规则进入 ERROR 并报警，由你决定是否手动平仓。
5. **价格冻结**：止损价、止盈价在入场单首次成交时计算一次（ADR-0005）。这时 `avg_cost` 就是首次成交价，后续成交不重算。计算用当天常规时段的开盘价；开盘价暂时拿不到时，等下一笔带开盘价的行情再算，期间不触发。
6. **价格合理性**：算出的价格必须为正，且止损价小于止盈价；否则规则进入 ERROR 并报警，不监控。
7. **冻结时已越过触发价**：立即触发（ADR-0007）。
8. **halt 期间**：规则暂停，不处理行情（ADR-0021）。恢复后的下一笔行情照常判断，已经越过触发价的立即触发。

## 理由

- 第 2 条是你的选择。按止损算更保守，但你选择按止盈算。这种情况只在用 K 线回放（dry-run）时出现；实时监控用逐笔行情，不会遇到。
- 第 3 条：不撤掉入场单余量的话，之后成交的部分没有止损止盈保护。
- 第 4 条是你的选择。比起一次失败就停下，「仍然成立就重发」更接近 ADR-0007「优先出场」的本意；设 3 次上限，避免异常时反复发单。
- 第 5、6 条把计算时机和失败方式说死，使 dry-run 和实时监控的结果可以复现。
